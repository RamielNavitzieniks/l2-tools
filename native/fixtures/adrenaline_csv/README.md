# CSVs sinteticos no formato dos scripts da Founder

Arquivos **inventados** para testar `conversores/adrenaline_csv.py`. Reproduzem so o
cabecalho, o separador `;` e o CRLF dos CSVs reais (GravadorQuest, QuestProbe,
LeituraSpots). Nomes de NPC, de jogadores e IDs sao ficticios. Algumas linhas sao
propositalmente invalidas (texto em coluna numerica, colunas faltando, hora 25,
tipo desconhecido) para exercitar o relatorio de perdas.

Os CSVs reais nao entram no repositorio.
